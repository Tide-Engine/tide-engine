# CRACKED

A port of the Unity game [CRACKED](https://store.steampowered.com/app/3917010/CRACKED/)
to Tide: two teams of glass-headed mages, spells that bounce, seven maps
that take turns, and a card for everyone who lost a round. One to eight
players, through the `rooms` menu; a team nobody plays for has a bot.

`DESIGN.md` says what was ported from where, and what wasn't.

## Playing

| | Keyboard and mouse | Gamepad |
|---|---|---|
| Move | W A S D | Left stick |
| Look | Mouse | Right stick |
| Fire | Left button | Right trigger |
| Block | Right button | Left trigger |
| Jump (hold for a jetpack) | Space | A |
| Reload | R | X |
| Pick a card | 1 to 5, or click | D-pad and A |
| Menu | Escape | |

A round goes to the team left standing. Two points are a round, and the
players of the team that lost it each pick one of five cards, which they
keep for the game. Five rounds win. The map changes after every round. The
floor under a map hurts and throws you back up: blocking as you land saves
the damage.

## Building

It's an opt-in prototype:

```
cmake --preset debug -DTIDE_PRIVATE_PROTOTYPES=ON
cmake --build --preset debug --target cracked cracked_tests
ctest --preset debug -R "^cracked_"
```

`tide run` in this folder builds it too. A run with no window:
`build/debug/bin/cracked --host --frames 600 --capture frame.png`.

The web build's `cracked_page` stages the page at
`docs/static/prototypes/cracked/index.html`, which the site serves at
`/prototypes/cracked/`.

## Files

| File | What's in it |
|---|---|
| `state.tide` | What the match is made of: seats, bullets, clouds, a map's pieces |
| `game.tide` | Seats and teams, the round's states, the maps' turns, the input |
| `player.tide` | A player: movement, firing, the shield, health, effects |
| `bullets.tide` | Bullets and their modifiers, and clouds |
| `collide.tide` | What touches what: casts and overlaps against boxes |
| `upgrades.tide` | The 38 cards |
| `bots.tide` | The bot |
| `maps.tide` | The seven maps, generated by `tools/make_maps.py` |
| `render.tide` and beside it | What's drawn of the world |
| `hud.tide`, `cards.tide`, `sound.tide` | The HUD, the cards, and what's heard |
| `test/` | The match's tests |
