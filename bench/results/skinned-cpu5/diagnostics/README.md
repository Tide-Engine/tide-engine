# Exploratory causal diagnostics

These bounded, unsaved experiments investigated the initial adverse comparison; none appends benchmark rows or establishes a production performance win. matched-phases-v2 retains the timer instrumentation protocol, logs, clocks and analysis. Adding timers changed code layout and reversed the sampling ranking, so phase results are diagnostic only.

layout48-v4 retains a private control relink with exactly matching candidate PE .text, a +48-byte unreachable prefix variant, preserved instruction/call/unwind checks and exact capture hashes. The reported view interval changed from about 30.458 to 28.511 ms, while observed graphics clock ranges differed (control 1110–1245 MHz, prefix variant 1005–1170 MHz). Several functions move together, and one short pair with different clocks cannot establish layout as the sole cause or justify production padding.

Raw artifact hashes are retained separately from normalized text hashes. Binary objects, libraries, executables, PDBs, maps and PNGs stay in scratch with identities in metadata. Only completed matched-phases-v2 and layout48-v4 evidence is included; the reproduction scripts are supplied as recorded diagnostic tools, not as steps in the final performance protocol.
